# 🔧 FixItLocal

> A community-focused platform for reporting and tracking local problems.

FixItLocal is a simple web-based community platform that allows users to report common problems in their local area, such as potholes, broken streetlights, garbage accumulation, water leakage, and other public issues.

The goal of the project is to encourage community participation and make it easier to identify and track problems that affect local neighborhoods.

---

## 🌟 Features

- 🏠 Clean and responsive home page
- 📝 Report local problems through a form
- 📍 Add the location of the reported problem
- 🏷️ Select problem categories
- 🔎 Search reported problems
- 🗂️ Filter problems by category
- 📊 Display problem statistics
- 🚦 Track problem status
- 📱 Responsive design for different screen sizes
- ⚡ Dynamic problem cards using JavaScript

---

## 📌 Problem Categories

FixItLocal currently supports the following categories:

- 🛣️ Road
- 💡 Streetlight
- 🗑️ Garbage
- 🚰 Water
- ⚡ Electricity
- 🏢 Public Property
- 📌 Other

---

## 🚦 Problem Status

Every reported problem can have one of the following statuses:

| Status | Description |
|---|---|
| 🟡 Reported | The problem has been submitted by a user. |
| 🔵 In Progress | The problem is currently being addressed. |
| 🟢 Resolved | The reported problem has been resolved. |
